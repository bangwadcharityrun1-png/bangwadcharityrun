ตั้งค่า Superadmin ครั้งแรก

ใช้หน้านี้เพียงครั้งเดียวเพื่อสร้างเจ้าของระบบ หลังจากนั้นให้เข้าสู่ระบบผ่านหน้า Admin Login ตามปกติ

กำลังตรวจสอบสถานะระบบ...
ระบบมี Admin แล้ว หน้า Setup ถูกปิดการใช้งานสำหรับการสร้าง Superadmin ใหม่
ไปหน้า Admin Login
บัญชีที่สร้างจากหน้านี้จะเป็น Superadmin คนแรกของระบบ กรุณาใช้ Email ที่คุณเข้าถึงได้จริงและตั้งรหัสผ่านที่คาดเดายาก
หาก Supabase เปิด Email Confirmation ไว้ ให้ยืนยันอีเมลก่อน จากนั้นกรอก Email/Password เดิมด้านล่างเพื่อเปิดสิทธิ์ Superadmin
