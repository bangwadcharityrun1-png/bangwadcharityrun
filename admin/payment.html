PromptPay และตรวจสลิป

QR รับเงินสร้างจากเลข PromptPay อัตโนมัติ และไม่พึ่ง API ตรวจสลิปภายนอก

โหมดตรวจในระบบ: Edge Function จะตรวจชนิดไฟล์/ขนาดภาพ, อ่าน Mini-QR จากภาพ, ตรวจ CRC ของ QR, ดึงธนาคารต้นทาง + Transaction Reference, สร้าง SHA-256 และ Perceptual Hash เพื่อกันสลิปซ้ำ/ภาพซ้ำ แล้วเก็บสลิปใน Private Storage
การตรวจแบบไม่เชื่อมธนาคารไม่สามารถยืนยันยอดเงินจริงหรือผู้รับเงินจาก Transaction ได้ 100% ใบสมัครจึงยังเป็น รอตรวจสอบ จน Admin เทียบกับรายการเงินเข้าและกดอนุมัติ
